# Використання AI-агента

## Передумови

- Відкрийте репозиторій у VS Code з GitHub Copilot Chat.
- Увімкніть режим Agent.
- Переконайтеся, що Git, Rust і Cargo доступні в середовищі.
- Перегляньте незбережені зміни. Агент має зберегти їх, а не перезаписувати.

## Повна генерація

У Copilot Chat виконайте:

```text
/init-agent
```

Запускайте команду в новому чаті: `/init` перехоплюється вбудованою командою
VS Code, тому може виконатися не цей prompt.

Оркестратор послідовно запускає `/git-init`, `/create-project`,
`/create-build`, `/create-actions` і `/check`. При першій помилці він зупиняє
процес, повідомляє етап і не запускає наступні команди. Повторний запуск
узгоджує наявні файли, не створює дублікати й не видаляє файли.

## Окремі команди

Команди можна запускати окремо з тим самим порядком залежностей:

1. `/git-init` — ініціалізувати Git лише якщо репозиторій ще не існує.
2. `/create-project` — створити Rust/Cargo-проєкт `hello`, бібліотечну
   функцію `add` і unit test `BasicAddition`.
3. `/create-build` — створити `ci.sh` і `ci.bat`.
4. `/create-actions` — додати GitHub Actions workflow для Linux, Windows і
   macOS.
5. `/check` — перевірити артефакти без редагування файлів.

Кожен prompt містить свої передумови, очікувані файли й перевірки. Запускайте
тільки потрібний етап, якщо попередні артефакти вже наявні.

## Очікувана структура згенерованого проєкту

```text
.
├── Cargo.toml
├── Cargo.lock
├── ci.sh
├── ci.bat
├── .gitignore
├── src/
│   ├── lib.rs
│   └── main.rs
└── .github/
    └── workflows/
        └── ci.yml
```

Бінарник має назву `hello`. Функція `add` і тест `BasicAddition` розміщені в
бібліотеці Rust. Workflow має одну job з матрицею `ubuntu-latest`,
`windows-latest`, `macos-latest`; на `push` і `pull_request` він запускається
для гілок `develop` та `master` і викликає локальні скрипти.

## Локальна перевірка згенерованого проєкту

```text
cargo build --release
cargo test
```

Також можна запустити повний локальний CI:

- Linux/macOS: `./ci.sh`
- Windows: `ci.bat`

Переконайтеся, що вивід тестів містить `BasicAddition` і всі тести пройшли.
Папки `target/` та `build/` виключені в `.gitignore`.

## Перевірка без змін

`/check` лише читає файли та виконує безпечні перевірки. Якщо виконуються
збірка або тести, Cargo має використовувати нову тимчасову директорію поза
репозиторієм. Команда не виправляє помилки; після звіту запустіть відповідну
команду генерації, щоб виправити проблему.
